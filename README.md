# Selenium Advanced Automation Framework

## Project Overview

This project demonstrates web application test automation using Java, Selenium WebDriver, Maven, and TestNG. It covers login validation, product selection, cart operations, explicit waits, Page Object Model (POM), and end-to-end test scenarios.

## Technologies Used

- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)
- Git and GitHub

## Application Under Test

[Rahul Shetty Academy Practice Client](https://rahulshettyacademy.com/client/)

## Automated Test Coverage

- Browser and environment configuration
- Browser launch and element identification
- Login functionality and validation
- Login page using Page Object Model
- Explicit waits and synchronization
- Product selection and cart validation
- End-to-end automation flow
- Data-driven testing
- TestNG suite execution and regression testing

## Framework Highlights

- Reusable page classes using the Page Object Model
- Test execution and assertions using TestNG
- Maven dependency management
- Environment variables for sensitive test credentials
- Git-based version control

## Prerequisites

- Java JDK
- Eclipse IDE or another Java IDE
- Maven
- Google Chrome
- Git

## Setup and Execution

1. Clone this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure the required environment variables for test credentials.
4. Allow Maven to download the project dependencies.
5. Run the required TestNG test class or suite.

## Configuration

Set the following environment variables in your local test execution configuration:

- `TEST_EMAIL`
- `TEST_PASSWORD`

Do not commit real credentials, access tokens, or passwords to the repository.

## Test Reports

Test execution results can be reviewed in the TestNG output and reports generated by the local test run.
